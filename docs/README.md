# GitMini — Phase 통합 문서 (docs)

각 Phase마다 **통합 문서 하나**를 둔다. **작성·갱신 주체는 AI**이다.  
규칙: 루트의 `METHODOLOGY.md` §8.

## 문서 형식

파일명: `PHASE1.md`, `PHASE2.md`, `PHASE3.md`, …

한 문서에 **계획 · 과정 · 종료** 세 섹션을 둔다.

| 섹션 | 내용 |
|------|------|
| **계획** | 해당 Phase 목표, 작업 목록, 결과물 정의, Step 분해, 주의사항 (DESIGN.md 기준) |
| **과정** | Step별 진행 내용, 생성/수정된 파일, 주요 결정·이슈 (진행 시 AI가 보완) |
| **종료** | 검증 결과(빌드/테스트), 완료 요약, 다음 Phase 시 주의사항 (완료 시 AI가 기록) |
